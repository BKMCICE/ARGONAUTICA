# 开发辅助工具

本目录保留模型解析、量化、参考推理、代码生成、仿真和开发辅助代码。各工具的输入、依赖与可执行范围以脚本参数和对应源码为准。

`python tools/verify_source.py` 核对当前分发文件的 SHA，不构建、不访问设备，也不检查已排除的板级依赖。

当前演示软件的独立构建入口为 [`demo/software/build.py`](../demo/README.md)。历史机器绑定诊断、迁移缓存和完整比赛打包流程不属于本仓库的使用入口；不应通过全局替换路径或校验值，把不完整公开目录解释为已验完整工程。

本仓库没有下载器配置、个人许可证或厂商安装包。需要硬件实现时，按 [IP_RESTORE.md](../IP_RESTORE.md)准备获授权的开发环境。
