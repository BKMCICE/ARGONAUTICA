# 源码展示范围

本仓库为独立整理的源码展示目录，使用新的 Git 历史。它不携带原比赛仓库的提交历史、内部日志、历史验证包或 Release 附件。

## 保留内容

- 项目编写的 CPU、Cache、计算单元、接口控制和裸机软件源码。
- 仿真、测试、模型转换与参考计算代码。
- 有明确来源说明的模型与量化数据，以及原第三方许可文本。
- 能公开保留的工程、约束、软件配方和设计说明。

## 排除内容

- Pango DDR3、PLL、FIFO 等受限实现，以及按保守规则排除的相关 IP 包装内容。
- 预编译硬件／固件和组合 Flash 镜像。
- 本机工具、个人许可证、内部环境记录、迁移缓存及历史大包。
- 原仓库 Git 元数据和仅用于内部实测追踪的资料。

完整板级依赖因此不齐全。本仓库不会生成假占位实现来通过检查，也不声称缺件源码能够独立重现原系统的上板验收。缺失依赖须在具备相应授权的环境中重新生成或恢复，见 [IP_RESTORE.md](../IP_RESTORE.md)。

## 许可与发布

项目原创部分尚未授予统一开源许可证；第三方版权和条件分别适用。后续若选择原创部分的开源许可，应单独确认其适用文件，不能覆盖上游模型、基准、测试和厂商内容。

源码准备、推送到私有仓库与改为公开是不同操作。本文件只描述分发边界，不表示已经改变仓库可见性，也不表示获得了原完整系统中所有文件的公开授权。
