# 系统架构

ARGONAUTICA 将 RV32IM 处理器、存储子系统、定点计算加速单元及图像输入／显示模块组合成裸机目标检测系统。本仓库保留可展示的源码；厂商 DDR3、PLL、FIFO 等实现由获授权的开发环境提供，未在此分发。

## 处理器与存储

CPU 采用 IF、ID、EX、MEM、WB 五级流水，包含数据前递、load-use 停顿、访存反压、CSR 与异常处理。配置可选择乘除法与分支预测。指令和数据经 Cache 访问 DDR3；片上 TCM 用于热点代码和栈。

完整系统使用外部 DDR3 存放模型、激活工作区和采集帧。公开源码保留相关接口、所有权切换和缓存维护逻辑，但缺少的厂商存储／时钟实现仍是板级构建依赖。

## 计算与图像路径

HDMI 控制逻辑确认输入几何，采样模块生成 320×320 RGB 模型帧。CPU 将其转换成 CHW 定点输入，调度 YOLO-Fastest 1.1 的层运算，并通过 MMIO 调用分块计算单元。软件还负责非卷积运算、重标定和检测后处理。

这是 CPU 主导的软硬件协同推理设计，并非每帧视频都经过独立整网硬件流水线。网络结构、数据布局、量化参数和加速单元调用关系分别保存在软件源与模型目录中。

## 自动循环

完整系统的控制流程为：

```text
应用启动 → 等待有效输入 → 采集模型帧 → 量化与前向
        → 后处理和保护检查 → 发布结果 → 保持 3 秒 → 下一轮
```

每轮任务使用新的采集身份，检查输入与栈保护，再发布 COMPLETE。零检测轮次清除上一轮条目；错误处理采用停止并报告的方式，避免自动重试掩盖故障。

HDMI OUT 显示运行阶段、来源、类别、置信度和前向时间。原系统使用独立文字结果页，没有直接把输入图像与矩形框叠加输出。公开源码未提供可直接下载的位流或自启动镜像。
