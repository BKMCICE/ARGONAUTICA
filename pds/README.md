# PDS 工程参考

本目录保留通用片上 RAM、DDR／Cache 配置的工程与脚本，供了解顶层、宏、约束和实现流程。演示系统的可展示源码另见 [demo](../demo/README.md)。

Pango DDR3、PLL、FIFO 等受限实现未随仓库分发。原完整系统使用 PDS 2022.2-SP6.4 和 PGL50H／FBG484／-6 器件；硬件构建前须在相应授权环境中恢复匹配的 IP 及器件／仿真库。

公开目录中的工程引用可能指向这些明确缺失的依赖。不要删除相应设计或使用空模块来制造完整构建通过；参见 [IP_RESTORE.md](../IP_RESTORE.md)。

本仓库不提供已经验收的 BIT 或 Flash 镜像。重新生成的硬件须独立完成原约束时序、管脚、CDC 和实板检查。内部物理实现数据库与历史报告不在本仓库分发范围内。
