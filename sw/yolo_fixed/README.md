## 可选分块阶段计时

`YOLO_BLOCK_PHASE_PROFILE=1`仅用于RV32实板诊断，同时要求`YOLO_1X1_BLOCK=1 YOLO_LAYER_PROFILE=1`；默认0，拒绝主机MMIO模型计时。每64任务和每组最后任务测输入打包、MMIO传送、提交/等待、结果读回与Q24/输出；权重批次另计，原生引擎周期包含在等待窗口中。字段用`tools/summarize_block_phases.py`核对。低32位周期差假设单窗口短于2^32周期；保留原始计时/布局扰动和校准，不把采样比例当原程序整层占比。详见A06冻结记录（历史资料未随本源码展示版提供）。正式固件保持采样开关0。


## 可选DDR输入预打包

`YOLO_BLOCK_INPUT_CACHE=1`须同时`YOLO_1X1_BLOCK=1 YOLO_BLOCK_PHASE_PROFILE=0`；默认0。每个输入组在独立300KiB静态DDR scratch预打包一次，供多个输出批次读取；单批次或容量不足走原路径，缓存与输入/输出/权重/参数重叠及指针范围溢出在MMIO前拒绝。保持原硬件ID缺失回退、忙/错误/超时传播、Q24和权重驻留。`YOLO_LAYER_PROFILE`可另行开启做新一轮分层诊断，但禁止沿用A06旧阶段窗口解释。A07三轮dog实板候选尚待A08多图实体板回归；正式配置保持缓存开关0。详见A07（历史资料未随本源码展示版提供）。
