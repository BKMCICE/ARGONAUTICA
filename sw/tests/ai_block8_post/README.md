# A48 八输出硬件后处理隔离测试

本目录评估八输出 1×1 块的 Q24、bias、leaky、[-127,127] 饱和和打包读回。生产 `sw/yolo_fixed/main.c` 的调度器没有接入候选，正式 A44＋A45 不变。

`operator.c` 在同一编译单元包含当前实际生产函数作为控制，再包含生成的候选函数；共用原输入缓存。`generate.py` 提取生产函数并只替换后处理传输，`--check` 检查所有生成产物。模型、权重、参数、CHW 顺序和量化规则保持。模板来自已修复的 A32；旧四输出生成器使用冻结控制，避免被生产八输出变更污染。

## 可选 RTL 接口

`ENABLE_BLOCK=1, ENABLE_BLOCK8=1, ENABLE_QUANT=1, ENABLE_WINDOW=0` 选择新隔离分支，所有默认值仍为0。A331 `0x28` 原始八输出能力和 raw32 协议保留；新增 `0x2c = 0x41343831`（A481），旧硬件读回0。PDS 整机脚本仍拒绝 quant＋block8，避免本阶段未经完整物理审核的组合进入正式构建。

| 偏移 | 读写含义 |
|---|---|
| 0x200 | 状态：bit0 busy，1 done，2 error，3 packed valid；bits15:8 multiplier valid，23:16 bias valid。写4清除状态 |
| 0x204 | bit0启用，bit1 leaky；空闲写入会清空参数有效位及结果 |
| 0x208 | 参数游标0..7；写入重新开始一批参数，有效位清零 |
| 0x20c/0x210 | 有符号32位Q24 multiplier/bias；先mult后bias，写bias推进游标，末尾为8哨兵 |
| 0x21c/0x220 | packed游标0..15／顺序读回，末尾为16哨兵 |
| 0x224 | packed字数：outputs×ceil(pixels/4)，最多16 |
| 0x228/0x22c | 本任务后处理计数周期／元素数，只读 |

packed按输出通道排列，每字低字节对应前面的像素，每通道尾字未用字节为0；raw32结果仍可读，后处理成功后恢复其游标0。新寄存器要求字对齐、完整字节使能，非法访问、忙写、缺参数、数学越界和过读均闭锁结果并报错。参数驻留跨空间块；换输出批重新上传。新模式的CTRL done表示MAC与后处理都完成。

合法数学域沿用 `ai_q24_post.v`：有符号64位积、半值远离0取整，缩放结果拒绝超出[-2147483647,2147483647]，加bias拒绝int32溢出；负leaky用已证明的有界无符号实现。任意int32参数不等于任意组合都合法。

候选先验证参数、地址/别名及硬件空闲，再读A481；缺失时在任何写入前调用实际生产4/8通道回退。开始任务之后遇到error/timeout直接返回，不重算已写出的部分输出。测试程序失败即终止；不是通用容错恢复驱动。

## 验证边界

普通与ASan/UBSan主机验证包含独立CHW/int64/除法Q24参考、通道/空间尾批、group/stride/裁剪、只读输入、缓存别名和哨兵、旧4/8能力回退及错误注入。RTL协议验证另覆盖数学、忙写、复位、字节使能、参数边界和原始接口逐周期对照，主机故障模型不能代替RTL证据。

短实际RV32/DDR程序 `A48_SHORT=1` 覆盖11种几何，每种预热一次、交替计时三次；大空间缩为2×17，完整空间筛查另有独立ELF和记录。计时包围完整算子，包含验证、缓存打包、参数/权重/输入上传、等待、读回解包及CHW写回。仿真中轮询次数、引擎busy周期和MMIO事务分别核对，不以轮询量解释CPU占用率。

结果见 A48冻结证据（历史资料未随本源码展示版提供）。局部外围PDS探针使用人工2ns接口延迟，仅筛查资源与局部时序；不替代整机原始约束、DDR/FIC/113管脚、独立TA或板测。最多64→16结果字数是传输量变化，不是整网4倍加速。
