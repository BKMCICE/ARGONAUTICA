# 深度5×5权重驻留算子诊断（A11/A12）

**A11原型已通过三轮实板局部算子验证，耗时减少36.21%/35.95%/31.00%；尚未接入生产整网。** 已恢复原A07，正式成绩不变。完整证据及A12开工点（历史资料未随本源码展示版提供）。

当前源代码直接测试生产共享的`sw/yolo_fixed/dw5x5_block.h`，由默认关闭的`YOLO_DW5X5_BLOCK=1`接入生产YOLO分派器，且要求`YOLO_1X1_ACC32=1`以传播错误。正式A07产物仍单独保留。使用现有A02块引擎将25个权重分成9/9/7三组，每通道上传一次，ACK保留权重；一个任务最多计算八个相邻像素。CPU继续负责窗口打包、补零、Q24、偏置、leaky和裁剪，没有新RTL、DMA或乘法阵列。

算子支持size=5、ic=oc=groups、padding≤4、步长、边界、尾像素及裁剪输出区域。拒绝无效形状、空指针、索引/指针范围溢出，以及输出与输入/权重/参数重叠。量化/偏置范围遵循固定模型原有约定，不定义任意溢出参数行为。

调用期间独占AI单元。ID缺失在写MMIO前返回UNSUPPORTED；忙碌、硬件错误、有限轮询超时和读回错误须传播，后续任务失败时必须丢弃部分输出。主机诊断直接调用实际`conv_layer`，核验成功、ID缺失时generic回退，以及五类硬件错误/超时均返回失败且不调用旧点积。生产分派器仅对UNSUPPORTED/BAD_SHAPE使用旧路径。

原版比较器`a11_legacy5`提取生产generic分支的深度5×5运算，直接调用未修改的`ai_dot5x5`，使用显式测试张量。它按每像素三次旧点积重新打包/上传权重；它是该深度分支的专用比较器，不含整个生产分派器或其他卷积核分支。双方均包含窗口打包、DDR/MMIO、权重装载、空间循环、Q24和输出，以独立CHW标量和除法式Q24核验。

目标诊断预热后，对三种形状各做四组交替顺序配对：40×40/c4/stride1、40×40/c4/stride2、5×17/c2/stride1，padding均2。局部算子周期不等同整网速度或峰值利用率。
