# A10 深度 3×3 分块算子原型

**本原型不采用。** 完整RV32/DDR/RTL正确性通过，但三种形状的完整算子仿真耗时增加1.67%/2.89%/5.29%，候选实板SKIP、整网NOT_RUN。正式A07不变。A10完整证据及下一步（历史资料未随本源码展示版提供）。

独立诊断，未接入生产 YOLO 分派器，不改变 A07 正式文件或默认构建。使用既有 A02 块引擎：一个 3×3 窗口展开为九个有符号 INT8 通道，同一输入通道的最多八个相邻输出像素合为一个任务，单输出、单通道组、末组九通道。权重每个通道上传一次，ACK 保留权重。没有新 RTL、DMA 或额外乘法器。

`operator.h` 包含完整算子，CPU 负责窗口打包、边界补零、Q24、偏置、leaky 和裁剪；支持步长、尾像素及裁剪后的输出区域。仅支持 size=3、ic=oc=groups、pad≤2；拒绝空指针、无效形状、索引/指针范围溢出及输出与输入/权重/参数重叠。量化和偏置遵循现有固定模型的有效范围，不定义任意溢出参数的行为。

整个调用独占 AI 单元。缺失硬件 ID 在写 MMIO 前返回 UNSUPPORTED；参数不合法返回 BAD_SHAPE，忙碌、硬件错误、有限轮询超时或读回错误不能视为有效输出。后续任务失败可能留下先前的部分输出，调用方须丢弃整次失败结果。诊断中的选择包装器只在缺失 ID 时走原深度 3×3；这不是生产分派器接入或整网回退验收。

`main.c` 直接包含生产程序，基准使用原 `conv3x3_depthwise_reuse`，两侧均包含 CHW/DDR、打包、MMIO、权重装载、完整空间循环及 Q24。先预热，再以交替顺序测四组配对时间：

| scenario | 输入 H×W | 通道 | 步长 | padding |
| --- | --- | --- | --- | --- |
| 0 | 40×40 | 4 | 1 | 1 |
| 1 | 40×40 | 4 | 2 | 1 |
| 2 | 5×17 | 2 | 1 | 1 |

每组都对独立 CHW 标量和除法式 Q24 参考核验两侧结果及输出哨兵。主机版本还核对输入/权重/参数只读、权重驻留及任务次数，以及错误/超时、缺失 ID 选择和异常不能回退。主机模型不代替实际 RTL 或实板证据；局部算子周期也不代表整网速度。

独立构建示例（使用新的 F 盘输出目录）：

```powershell
. ./tools/env.ps1
make -C sw/tests/ai_dw3x3_block BUILD=F:/ARGONAUTICA_work/board_tests/a10_rerun OPT='-O2 -fstack-usage'
```
