# A19：缓存1×1完整算子阶段诊断

A19三轮实板诊断及原A16正式恢复、新显示确认均通过。120→255通道形状的缓存传输占抽样任务47.04%；16→96通道形状的Q24/写回占64.61%。完整证据与A20开工点（历史资料未随本源码展示版提供）。以下说明的主机、短RTL及完整实板范围分别保留。

诊断直接在两个独立翻译单元中调用生产`conv1x1_block`：control关闭计数，profile显式开启`YOLO_BLOCK_PHASE_PROFILE`及`YOLO_BLOCK_CACHE_PHASE_PROFILE`。后者补齐缓存预打包和缓存到PDATA传输的采样。两者分别占用原有大小的300KiB诊断缓存；这不是正式应用新增缓存，也不是两个算法的提速对照。代码布局和缓存位置不同，测得差异只能作为采样扰动参考。

正式通用构建的新开关默认0；A19必须证明关闭后整网BIN逐字节等于已验证A16。没有改模型、量化、RTL或Flash。每个任务仍1/64采样并包含最后一个任务，阶段时钟开销保留，不用空CSR校准伪造未采样耗时。缓存整体预打包、所有权重装载和抽样任务阶段的统计范围不同，不能直接相加冒充完整算子分解或DDR停顿统计。

实板诊断包含小形状2×9/10→5、3×7/17→9，以及A18热点20×20/120→255、40×40/16→96。预热后每形状四组交替control/profile；计时包含检查、输入缓存构建、权重、MMIO、Q24及输出。两输出逐字节比较、前后哨兵及只读输入/权重/参数校验，并匹配独立Python CHW/int64 Q24参考的FNV。主机另用逐元素C参考和ASan/UBSan校验两种数据模式。固定模型Q24范围与AI独占/张量稳定约定不变。

短RTL构建`A19_SHORT=1`只执行两个小形状，使用相同生产control/profile源但**不是实板大形状ELF**。两份ELF各自审计与SHA绑定；短RTL只证明对应小形状的实际RV32/DDR/块事务、补零、采样计数和正常返回，不能当作大形状或整网仿真。DDR模型范围显式扩大至2MiB并断言无地址绕回。
